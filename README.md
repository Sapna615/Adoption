# 🐾 PetHaven — Pet Adoption & Care Platform

> A modern, responsive web platform designed to make pet adoption easier while helping people understand responsible pet ownership and care.

PetHaven is a front-end web application that brings together **pet adoption, pet matching, adoption preparation, lost & found support, adoption-center discovery, and pet-care resources** in one place.

The goal is not only to help users find a pet, but also to help them determine whether they are ready to adopt and prepare for responsible pet ownership.
